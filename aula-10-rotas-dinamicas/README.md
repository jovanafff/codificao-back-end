# Aula 10 - Rotas Dinâmicas

## 📚 Sobre a aula

Nesta aula foi estudado o conceito de **rotas dinâmicas no NestJS**, aprendendo como criar rotas que recebem valores através da URL e utilizá-los dentro dos controllers e services.

Também foi trabalhada a organização da aplicação utilizando **Controllers, Services e Modules**, seguindo a estrutura padrão do NestJS.

## 🎯 Objetivos

- Compreender o funcionamento das rotas dinâmicas.
- Aprender a receber parâmetros através da URL.
- Utilizar parâmetros dentro dos Controllers.
- Integrar Controllers e Services.
- Organizar os arquivos de uma aplicação NestJS.
- Criar endpoints para consulta de dados.

## 🛠️ Tecnologias utilizadas

- Node.js
- NestJS
- TypeScript
- NPM

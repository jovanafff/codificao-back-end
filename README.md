# 💻 Codificação Back-End

## 📌 Sobre o projeto

Este repositório foi criado para armazenar os estudos, atividades e projetos desenvolvidos durante o aprendizado de desenvolvimento **Back-End**.

O objetivo é colocar em prática conceitos de programação, criação de APIs, manipulação de dados, regras de negócio e integração entre diferentes partes de uma aplicação.

## 🚀 Tecnologias utilizadas

- JavaScript
- Node.js
- APIs REST
- Git
- GitHub
- Express
- Visual Studio Code
